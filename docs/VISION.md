# Vision & Core Pillars

## Vision

Build a map-driven civilization evolution simulator where geography, ideology, logistics, and heroes shape millennia of history -- from prehistoric tribes to rival interstellar powers.

## Core Pillars

1. **Map-Driven Geopolitics** -- Geography shapes destiny
2. **Hidden Tech Emergence** -- No visible tech tree; technology emerges from systemic pressure
3. **Logistics & Supply-Based Warfare** -- Logistics determines victory, not just army size
4. **Terrain Shapes Destiny** -- Desert, mountains, rivers, coastlines define what's possible
5. **Epic Historical Arcs via Heroes** -- Named individuals catalyze historical inflection points
6. **Earth to Space Transition** -- Based on play, not scripted progression

## Emergent Systems Philosophy

The game must:
- Be probabilistic, not deterministic
- Use weighted thresholds rather than fixed unlocks
- Allow unexpected collapses or runaway empires
- Ensure same seed does not equal same guaranteed outcome

Randomness must be bounded but influential.

## What This Is NOT

- Not an RTS micro-unit game
- Not multiplayer-focused
- Not scripted history
- Not a traditional 4X with tech tree clicking
